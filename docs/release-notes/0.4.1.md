# BitGarth 0.4.1

## Highlights

- Bitcoin accounts added from an xpub now fetch the transaction history of
  every address BitGarth discovers, and start doing so right after the account
  is added.
- If BitGarth cannot open its data when it starts, it now stops with an
  explanation of what went wrong instead of starting in a broken state.

## Fixed

- Transactions on addresses discovered in a Bitcoin account created from an
  xpub could be missing, because those addresses were checked for a balance but
  their history was never fetched. That history is now fetched.
- A newly added xpub account no longer waits for a later scheduled sync before
  its discovered transactions appear.
- When BitGarth cannot open or upgrade its data at startup, including data
  written by an incompatible version, it now exits with a diagnostic describing
  the problem and saves it as `startup-error.txt` in the project directory. Your
  existing data is left untouched. Previously it could start anyway, and signing
  up or signing in would then fail.
- A temporary problem opening BitGarth's data, such as a file locked by another
  program, no longer leaves parts of the app failing until you restart it.
  BitGarth tries again the next time the data is needed.
- Sign-up and sign-in no longer blame the database for every internal error or
  suggest waiting a minute. The message now points to the application logs, or
  to the person who runs the instance.
- While BitGarth cannot read its data, it no longer logs a warning every
  second. It retries every 30 seconds and repeats the warning at most every
  five minutes.

## Notes

- A new *Startup troubleshooting* guide, linked from the README, explains where
  to find the startup diagnostic on each platform and how to recover safely.
  The diagnostic stays on your machine and is not sent to BitGarth's servers.
- BitGarth can now be installed with Homebrew on macOS (Apple Silicon) and
  Linux (x86-64). Add the tap with `brew tap ferntrail/tap`, then run
  `brew install ferntrail/tap/bitgarth-web` for the web server, or
  `brew install ferntrail/tap/bitgarth-cli` for the command-line client.
