# BitGarth 0.3.2

## Highlights

- macOS CLI downloads now carry a developer signature and are submitted to
  Apple for notarization. You should no longer see an unidentified-developer
  warning when running the released CLI binary on macOS.

## Fixed

- The CLI now reports the same version as the BitGarth app, instead of always
  reporting 0.1.0.

## Notes

- GitHub download filenames now start with `bitgarth-cli-` to distinguish the
  command-line client from the app. Update download scripts that use the old
  `bitgarth-` filenames; the executable is still named `bitgarth`.
- This release improves CLI distribution. App features and wallet data are
  unchanged.
