# BitGarth 0.3.1

## Highlights

- Bitcoin transaction history now finishes downloading when BitGarth reads from
  your own mempool server, such as the one running on Umbrel.

## Fixed

- With **Settings → Bitcoin Explorer → Mempool Base URL** pointed at your own
  mempool server, an account could download the same last page of transactions
  again and again and never finish its history. BitGarth now recognises that
  ending and completes the history once every transaction is accounted for.
- Closed a weakness in a networking library BitGarth uses, where a client could
  drive up memory use on your install by sending a stream of empty requests.
