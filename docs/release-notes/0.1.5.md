# BitGarth 0.1.5

## Highlights

- Wallet values can now use real market prices from CoinGecko, with your
  explicit consent and an optional CoinGecko API key for higher limits.
- BitGarth now tells you when a newer version is available and warns when the
  running build has drifted from the server.

## New

- CoinGecko price fetching for wallet values, controlled from the navbar and
  Settings with a clear consent toggle.
- Historical daily price backfill so past-dated wallet values reconcile over
  time.
- Discover and add manual assets from the CoinGecko catalog, with a live search
  count of matching assets.
- In-app upgrade awareness: update-status banner, channel-aware upgrade notice,
  and an automatic throttled check after login.
- Server/client build-drift detection that prompts a reload when they diverge.
- hledger export now includes network-fee accounts, a root include tree, and
  signed balance deltas for correct asset postings.
- Settings "Security" tab renamed to "Account", plus a navbar identity dropdown
  with deep links and larger botanical-ledger identicons.

## Fixed

- BTC ledger values repair on database open and exclude network fees so
  balances and exports stay correct.
- Manual assets no longer duplicate, and CoinGecko tickers are not persisted as
  display glyphs.
- CoinGecko API keys are redacted from logs and the loader fails closed on a
  bad key.
- The build endpoint is gated to web server contexts and the drift notice
  clears once the server build matches.
