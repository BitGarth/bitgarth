# BitGarth 0.4.4

## Highlights

- BitGarth is now open source under the GNU Affero General Public License,
  version 3.
- Secure connections no longer trust emSign intermediate certificates that
  have been distrusted.

## Fixed

- Secure connections no longer trust emSign intermediate certificates that
  have been distrusted.
- The components BitGarth uses for secure connections now include the latest
  security fixes.
- On the free plan, the *Holdings Report* and account pages now keep their
  dates in the page address when the default range is longer than the
  nine-month window, so reloading or copying the link keeps the same dates.
