# BitGarth 0.1.7

## Highlights

- The free tier now has a clear limit on synced accounts, and BitGarth prompts
  you to upgrade when you reach it.

## New

- Account limits on the free tier, with prompts on inactive accounts that link
  straight to the Upgrade page (renamed from Payments).
- Each paid plan's terms now appear beside its card, with yearly pricing in
  whole dollars.

## Fixed

- Wallet lookups now surface CoinGecko rate-limit messages instead of a generic
  internal error.
- More reliable manual-asset price lookups, including cached results when no
  CoinGecko API key is set, and no reuse of stale price details.
- UI polish: warmer notice surfaces, quieter account-list accents, and a stray
  section number removed from the Wallets and Upgrade pages.
