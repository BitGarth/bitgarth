# BitGarth 0.1.4

## Highlights

- Manual assets are now backed by a CoinGecko-sourced asset catalog, so you can
  search and add a far wider range of coins and tokens.
- Wallet reports gain a Prices section where you can set your own price for an
  asset and see it applied to your holdings.

## New

- Searchable manual-asset picker (combobox) ordered by market-cap rank, with
  many new networks including Monero, Tezos, Zcash, Dash and Polkadot.
- User price overrides, shown as inline price chips in desktop and mobile
  wallet reports.
- Etherscan API key visibility: a set/unset badge in Settings and warnings on
  the Wallets and Transactions pages when a key is missing.
- Migration of legacy custom accounts into the new manual-asset model, with
  confirmation options on the Account page.
- Wallet Data Export V4, which now backs up and restores your stored API keys.
- Settings sections are deep-linkable via a query parameter.

## Fixed

- Manual ERC-20 assets are no longer rejected unless they were USDC on Ethereum.
- Imported xpub addresses are bootstrapped correctly and empty HD sync work
  sets are preserved.
- Stored API keys are kept in a dedicated table and blank keys are rejected.
- Corrected the Cardano ledger model and the Uniswap unit code.
