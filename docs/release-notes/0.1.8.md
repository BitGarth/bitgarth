# BitGarth 0.1.8

## Highlights

- Self-hosted installs now hold to the correct free-tier limits on their own —
  refreshing from the latest plan when they can reach our servers, and keeping
  the last known limits when they can't.
- Manual tracking now reaches everything BitGarth already knows from your synced
  wallets: search finds those assets — including Bitcoin and Ethereum — and you
  can add manual accounts for them using the same names and units.

## New

- Free-tier limits stay accurate on self-hosted installs without a constant
  connection: they update from the latest plan information and fall back to the
  last known limits while offline.
- You can add manual accounts for the assets BitGarth tracks in synced wallets,
  including Bitcoin and Ethereum, reusing their existing names and units.
- Umbrel users now get an in-app notice when a new version is available, pointing
  to the Umbrel app store rather than showing a Docker command that wouldn't
  apply.
- On hosted BitGarth, free users are now told — at sign-up and when exporting
  wallet data — how long inactive data is kept before it is removed, and
  inactive free accounts are cleaned up after that grace period.

## Fixed

- Visiting a page that does not exist now returns a proper "not found" response
  instead of a soft one.
- Manual asset search keeps its original ordering and result counts.
- Wallet rows no longer show confusing account-usage text.

## Notes

- The free tier now allows 50 accounts. Balance assertions and hledger export are
  included on Free; syncing full transaction history stays on the paid plans.
- On hosted BitGarth, the terms were updated to describe how inactive
  free-account data is retained and removed.
